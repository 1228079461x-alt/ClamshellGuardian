# 合盖守护 0.1.1 Beta

此版本修复 0.1.0 在 macOS 27 上开启 `SleepDisabled` 后，合盖时显示器可能没有可靠熄灭的问题。

- Helper 每 0.5 秒检查系统上盖传感器。
- 每次检测到真正合盖后，立即执行文档支持的 `pmset displaysleepnow`。
- 同一次合盖只发送一次；命令失败会重试，开盖后为下一次合盖重新待命。
- 不修改亮度设置，因此开盖后不会残留最低亮度。
- IPC 提升到 v2，升级时会要求管理员权限替换旧 Helper，避免新界面继续使用旧后台。
- 整机任务、60 分钟上限、15% 电量、热状态、心跳和可选断网保护保持不变。

注意：`displaysleepnow` 会让当前连接的显示器一起休眠。附件仍为 ad-hoc 签名、未经 Apple 公证的 Beta；请从本 Release 下载并核对 `SHA256SUMS.txt`。
