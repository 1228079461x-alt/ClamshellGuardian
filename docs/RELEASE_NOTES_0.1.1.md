# 合盖守护 0.1.1 Beta

## 这个应用是做什么的？

点击“开始 60 分钟守护”后，合上 Apple Silicon MacBook 的屏幕，显示器会熄灭，但 Mac 不睡眠；已经运行的 Codex、Claude Code、Chrome、终端命令和其他后台任务都会继续运行。60 分钟到期后，系统恢复普通合盖睡眠。

开盖时可能需要输入 Mac 登录密码。这只是 macOS 在显示器关闭后的正常锁屏，不表示电脑在合盖期间睡眠。

## 0.1.1 修复了什么？

0.1.0 虽然阻止了系统睡眠，但没有主动发出显示器休眠命令，因此在部分系统上合盖后屏幕可能仍亮。0.1.1 现在会检测真实合盖动作，并立即关闭显示器；开盖后不会遗留最低亮度。

如果装过 0.1.0，首次打开 0.1.1 时需要再次输入管理员密码，以便把旧 Helper 更新为 v2。界面显示绿色“✓ 可以合盖”和倒计时后，更新才算完成。

## 最简单的使用方法

1. 下载 `ClamshellGuardian-0.1.1-arm64-beta.zip`，解压并把“合盖守护.app”拖进“应用程序”。
2. 打开应用，点击“开始 60 分钟守护”。
3. 首次使用时输入管理员密码，并保持开盖等待 10 秒测试。
4. 看到绿色“✓ 可以合盖”后再合盖。
5. 提前结束时，从菜单栏盾牌中点击“立即停止”。

## 重要限制

- 只支持 Apple Silicon、macOS 14 或更高版本。
- 不只保护 Codex，而是让整台 Mac 上已经运行的应用和后台进程继续运行。
- 不主动连接 iPhone 热点；原有 Wi‑Fi 正常时继续使用原网络。
- 默认开启断网保护：连续离线 10 分钟后结束。只跑本地任务时可在启动前关闭。
- 不控制风扇，也不要求 Macs Fan Control。
- `pmset displaysleepnow` 会让当前连接的显示器一起休眠，不能只关闭内置屏幕。
- 电池供电降到 15%、系统严重过热、应用失联约 15 秒或达到 60 分钟时，会恢复普通睡眠策略。
- 当前附件为 ad-hoc 签名、未经 Apple 公证的 Beta；请只从本 Release 下载并核对 `SHA256SUMS.txt`。
